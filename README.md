# Integer Addition and Subtraction

A static browser mathematics game with symbolic water and fire characters and an exact signed number-line journey.

## Play

After GitHub Pages is enabled: https://keeganfinlayson.github.io/integer-battles/

## Hosting

In repository Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/ (root)**, and Save. All pictures are included in `assets/`; keep that folder beside `index.html`.

No installation, build step, backend, or student login is required. To run locally, serve this folder with any static web server.

Subtraction uses an elemental wizard to cast a cloud containing a minus sign over the second group. The cloud settles before fire changes into water, or water changes into fire, then clears. The wizard matches the first group's water/fire species, distinguished by a purple hat and wand. The first group keeps its sign. The transformed characters then turn and combine using the existing signed-unit rules. Addition has no spell.

All active artwork is included. The previous cloak-change sheets remain in the archive but are no longer loaded by the game.
