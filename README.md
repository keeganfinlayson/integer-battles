# Integer Addition and Subtraction

A static browser mathematics game with symbolic water and fire characters and an exact signed number-line journey.

## Play

After GitHub Pages is enabled: https://keeganfinlayson.github.io/integer-battles/

## Hosting

In repository Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/ (root)**, and Save. All pictures are included in `assets/`; keep that folder beside `index.html`.

No installation, build step, backend, or student login is required. To run locally, serve this folder with any static web server.

This release preserves the current game and includes its 12 active visual assets. Source build: 91cc0ed87143273339d83b26fa0be69659a0723d.
